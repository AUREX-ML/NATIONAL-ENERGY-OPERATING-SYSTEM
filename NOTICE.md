# Notice

## Programme Status

This repository contains working programme architecture for the proposed National Energy Operating System Programme.

The material is intended for structured review, validation, and refinement. It should not be interpreted as proof of government approval, regulatory approval, procurement, deployment, or operational authority.

## Institutional Boundary

The programme does not replace existing public authorities, regulators, utilities, system operators, market institutions, asset owners, or certified protection and control systems.

Any future monitoring, coordination, dispatch, aggregation, settlement, or market function must operate within explicit legal, regulatory, contractual, grid-code, delegated, or owner-approved authority.

## Repository Naming

The earlier GitHub repository name reflected the technical framing around National Distributed Energy Resource Management Systems. The current programme name used in the documentation is:

> National Energy Operating System Programme

National DERMS remains a technical layer inside the broader programme.

The intended official GitHub repository target is:

> `AUREX-ML/NATIONAL-ENERGY-OPERATING-SYSTEM`

## Evidence Boundary

Architecture defines what may need to exist. Evidence establishes what actually exists.

Claims about benefits, readiness, economics, authority, and deployment should be treated as hypotheses until validated by appropriate evidence and stakeholder review.
