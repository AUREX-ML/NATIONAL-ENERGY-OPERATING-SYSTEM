## Repository Logic

```text
Why it matters
  ↓
What is being built
  ↓
How it works
  ↓
Who must govern it
  ↓
How it is proven
  ↓
What evidence is required
```

## Document Status Vocabulary

| Status | Meaning |
|---|---|
| Draft | Material exists but needs review and refinement. |
| Working draft for validation | Material is suitable for stakeholder review but not final approval. |
| Working draft for Phase II pilot definition | Material defines the next pilot-planning work, but does not prove site selection or implementation. |
| Architecture baseline | The conceptual structure is defined and ready for reconciliation against real evidence. |
| Implementation evidence required | The document defines what should exist, but field, technical, legal, or operational proof is still required. |
| Approved | Formally accepted by the appropriate authority. |
