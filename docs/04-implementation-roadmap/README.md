# Implementation Roadmap

This section explains how the programme should move from concept to evidence.

## Scaling Logic

The programme should not begin by claiming national operational authority. It should earn responsibility through staged proof:

```text
Laboratory proof
  ↓
Facility EMS pilot
  ↓
Repeatable Facility EMS product
  ↓
Portfolio aggregation
  ↓
Regional DERMS prototype
  ↓
Regional DERMS pilot
  ↓
National DERMS architecture validation
  ↓
National Energy Operating System readiness
```

## Governing Rule

> Scale follows evidence.

Each stage must prove technical capability, operational reliability, safety, cybersecurity, user value, economics, authority boundaries, and institutional readiness before the programme advances to the next level.

## Phase II Focus

The immediate Phase II task is Facility EMS pilot definition and site selection. This does not mean a pilot site has been selected or implementation has begun. It means the programme is defining the evidence, templates, boundaries, and decision gates required before any live pilot claim can be made.

## Immediate Implementation Questions

- What is the first credible Facility EMS pilot site?
- What equipment, meters, protocols, data, and control functions must be integrated?
- What baseline will prove value?
- Which institution or customer authorizes the pilot?
- What controls prevent unsafe operation?
- What evidence will be accepted as proof?
