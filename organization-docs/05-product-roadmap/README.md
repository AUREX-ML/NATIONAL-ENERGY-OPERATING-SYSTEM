# Product Roadmap

This section defines how the organization progresses from laboratory proof to nationally significant distributed-energy coordination infrastructure.

The roadmap is evidence-gated. Each stage must prove the capability and trust required for the next level of responsibility.

## Documents

- [Product Roadmap](./product-roadmap.md)

## Governing Principle

> The organization earns the right to manage a larger energy system only by demonstrating that it can reliably coordinate the system immediately below it.

The roadmap follows the sequence:

Facility EMS Laboratory → Facility EMS MVP → Facility EMS Production → Portfolio Aggregation → Regional DERMS Prototype → Regional DERMS MVP → Utility Pilot → National DERMS Prototype → National DERMS.
