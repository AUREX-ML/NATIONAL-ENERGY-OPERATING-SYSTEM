# Talent Acquisition, Selection & Onboarding

## Purpose

Create a repeatable system for converting capability gaps into productive, trusted contributors.

```text
Capability Gap → Role → Candidate Pipeline → Selection → Offer → Onboarding → Productive Autonomy
```

## Hiring Principles

- Hire for a defined organizational need, not vague growth.
- Evaluate evidence of capability rather than prestige alone.
- Use structured, role-relevant assessment.
- Keep candidate treatment professional and consistent.
- Do not create permanent headcount where contracting, partnership or automation is economically superior.

## Talent Sources

Potential channels include direct recruitment, referrals, universities, apprenticeships, open-source communities, technical communities, industry networks, contractors and strategic partners.

Open-source participation can serve simultaneously as a contribution mechanism, learning environment and observable talent pipeline.

## Selection Architecture

```text
Application / Discovery
       ↓
Basic qualification
       ↓
Structured interview
       ↓
Role-relevant evidence / work sample
       ↓
Technical or functional assessment
       ↓
Values / working-behavior assessment
       ↓
References where appropriate
       ↓
Decision
```

Selection criteria should be defined before evaluating candidates wherever practical.

## Onboarding

Every newcomer should understand:

- Mission and strategy
- Product and operating model
- Role and expected outcomes
- Manager and team interfaces
- Security and safety requirements
- Tools and access
- Documentation architecture
- Working norms and culture
- Initial objectives

## Productive Autonomy

The goal of onboarding is not merely completing forms. It is reaching the point where a person can independently produce expected outcomes within defined constraints.

```text
Context → Guided Work → Feedback → Independent Execution → Productive Autonomy
```

## 30/60/90-Day Pattern

**First 30 days:** context, systems, relationships, initial guided contribution.

**By 60 days:** meaningful ownership with regular feedback.

**By 90 days:** increasingly independent execution against measurable outcomes, adjusted for role complexity.

## Definition of Done

The acquisition system is mature when roles originate from real capability gaps, candidates are evaluated consistently, hiring decisions have evidence, onboarding transfers institutional context and security responsibilities, and new people can reach productive autonomy predictably.
